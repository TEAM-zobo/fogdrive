안개지도 기능별 테스트 케이스

21개 TC · 모두 자동화. 이 문서는 qa/fogqa/cases.py에서 생성됩니다(python3 -m fogqa tc-doc).

모든 TC는 Pleos Connect Emulator에서 실제 SDK 경로로 실행됩니다. 차량 신호는 Virtual Console API로, 위치는 adb emu geo fix로 주입하고, 화면은 UIAutomator로 판독합니다. 각 TC는 앱 데이터 초기화와 차량 상태 초기화(P단, 도어 닫힘, 와이퍼·전조등 끔, 동승자 없음)에서 시작합니다.
