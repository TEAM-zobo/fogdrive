# 시연 페르소나와 시연 영상 시나리오: 40대 아빠 A씨

부릉탐험대의 시연(서비스 시연 영상, 2차 PT 실동작 시연, 앱의 '시연 주행')은 모두 이 한 사람을 기준으로 합니다. 기획서(`02-app-introduction.md`) **4. 주요 사용 시나리오**의 A씨이며, 앱에 쌓아 두는 지난 기록, 앱의 시연 코스, 시연 영상의 장면이 모두 A씨의 일주일입니다. 실제 사람의 기록이 아닌 시연용 가상 기록이며, 영상과 PT에서 그렇게 밝힙니다.

## 1. A씨

**40대 초반 아이 아빠 A씨** · 위례 거주, 양재 출근, 유치원생 아이 한 명. 탐험대 이름은 아이 이름을 딴 '도현 탐험대'.

| 구분 | 생활 | 부릉탐험대 |
|---|---|---|
| 평일 | 아침에 아이를 유치원에 내려 주고 출근, 저녁에 퇴근 | 키즈모드로 등원, 유치원 하차 깃발, 출근 20번째에 「프로 출근러」 |
| 주말 | 토요일마다 가족(아내·아이)과 가까운 곳으로 나들이 | 도감·추천으로 안 가 본 곳 고르기, 키즈모드 음성, '함께 탐험' |
| 분기 1회 | 강원도 1박 2일 가족 여행 | '멀리 떠난 날'로 「주말 원정대」, 강원이 도감에 색칠됨 |
| 바람 | 아이와 함께하는 차 안 시간과 가족 나들이를 기록으로 남기고 싶음 | 탐험대 이름으로 쌓이는 가족 기록 |

장소 (모두 실제 장소, 경로는 OSRM 실제 도로):

| 장소 | 위치 | 내비 즐겨찾기 |
|---|---|---|
| 집 (베이스캠프) | 송파꿈에그린 위례24단지, 서울 송파구 위례광장로 121 (1,810세대, 위례에서 가장 큰 단지) | 집 |
| 유치원 | 서울 송파구 거여2동 (집에서 2.5 km) | 장소 '유치원' |
| 회사 | 현대자동차 본사, 서울 서초구 헌릉로 12 | 회사 |
| 토요일 나들이 | 남한산성, 용인 에버랜드, 수원 화성, 하남 스타필드, 광주 화담숲 (번갈아) · 시연: 올림픽공원 | (스타필드 하남은 장소로 저장) |
| 분기 여행 | 강릉 경포해변 (집에서 203 km) | — |

앱은 집·회사·장소를 Pleos NaviHelper `getBookmarkInfo`로 읽어 베이스캠프, 주행 이름("집 → 유치원", "유치원 → 회사"), 출근 판정에 씁니다. SDK에는 즐겨찾기를 쓰는 API가 없어 에뮬레이터 내비 화면에서 한 번 등록해 둡니다.

## 2. 지난 기록 (시연일 직전 19일 근무 · 약 4주)

| 구분 | 내용 | 거리 |
|---|---|---|
| 평일 등원 | 08:05 집 → 유치원 (아이 뒷좌석) | 2.5 km |
| 평일 출근 | 08:25 유치원 → 회사 | 13.6 km |
| 평일 퇴근 | 18:35 회사 → 집 | 12.2 km |
| 토요일 | 가족 나들이 왕복 (아내 앞좌석·아이 뒷좌석) | 편도 8–31 km |
| 쉬는 날 | 일요일, 공휴일(개천절 대체공휴일·한글날) | — |

근무일은 19일이라, 시연일(평일) 출근이 **20번째**가 되어 「프로 출근러」를 받습니다. 올림픽공원과 강원도 여행은 기록에 넣지 않고 시연에서 직접 달립니다.

2026-11-02(월) 시연 기준으로 앱에 쌓인 것:

- 10/02 ~ 10/31, 주행 67건, 768 km, 하차 43곳, Lv.14
- 도감: 시·도 2곳(서울·경기), 시·군·구 8곳, 읍·면·동 73곳
- 스탬프 7/11: 첫 시동, 새 도시 첫발, 함께 탐험, 읍·면·동 10곳, 주말 드라이브, 탐험 주간, 4주 연속 탐험
- 칭호: 아직 없음, 「프로 출근러」 19/20

기준 자료: 자동차 1대당 하루 평균 주행거리 38.7 km(2024, 한국교통안전공단), 수도권 평균 통근 거리 20.4 km(통계청·SKT, 2023). A씨는 하루 약 28 km(등원+출근 16 km, 퇴근 12 km)를 달립니다.

찍을 때 지킬 것:

- 주행 중에는 조작 화면을 보여 주지 않습니다(실제 앱도 주행 중에는 지도만 보임). 조작은 모두 P단에서.
- 빨리 감은 구간(4·6·12·14)은 소리를 빼고, 음성이 나오는 순간만 1배속으로 앱 소리를 살립니다. 음성 자막을 화면에 함께 띄웁니다.
- 각 장면 옆에 "사용 데이터"(Pleos SDK)를 작게 붙여, 차량 앱이어야 하는 이유가 보이게 합니다.
- 끝 화면에 "화면은 에뮬레이터 실동작, 지난 주행 기록은 시연용 예시"라고 표시합니다.

## 6. 만드는 법

```bash
python3 tools/demo/persona/fetch_routes.py         # 장소를 바꿀 때만: 실제 도로 경로 → routes.json (이름을 주면 그 경로만)
python3 tools/demo/persona/gen_courses.py          # 앱의 시연 코스(DemoCourses.kt)
python3 tools/demo/persona/make_persona_backup.py  # 시연일(오늘) 직전 19일 근무 기록 → tools/demo/out/persona-backup.json
python3 tools/demo/prepare_demo.py --serial emulator-5554   # 앱 초기화 → 기록 불러오기, 집에 주차
```

- 시연일은 평일이어야 출근이 20번째로 잡힙니다(주말이면 `--today`에 다음 평일을 줌). `--commutes 20` 이상이면 「프로 출근러」를 이미 받은 상태가 됩니다.
- 내비 즐겨찾기(집·회사·유치원)를 등록하고, 설정에서 탐험대 이름 '도현 탐험대'를 넣습니다. 키즈모드는 끈 채로 시작해 영상 3번 장면에서 켭니다.
- 시계를 바꿔 찍지 않아도 됩니다(토요일 장면도 결과 카드는 같음). 바꾼다면 Pleos 내비는 시계가 실제 시간과 다른 상태로 새로 켜지면 "서비스 연결 중"에서 멈추므로, 실제 시간으로 내비를 먼저 띄운 뒤 바꿉니다.
- 11번 '경유지 추가'는 실제 내비 경로에 경유지를 넣지만, 시연 주행은 정해진 코스를 달립니다. 경유지를 지나는 화면까지 맞추려면 그 경유지를 지나는 올림픽공원 코스를 따로 만듭니다(fetch_routes.py의 LEGS).
- 같은 곳에 몇 분 안에 다시 도착하면 하차로 치지 않아 주행이 끝나지 않습니다. 장면을 다시 찍을 때는 앱을 재시작하고, 지난 시도는 최근 주행에서 지웁니다.
