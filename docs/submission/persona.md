# 부릉탐험대 시연 영상 제작 가이드 (시연 페르소나: 40대 아빠 A씨)

이 문서 하나로 부릉탐험대 **서비스 시연 영상**을 만들 수 있게 정리했습니다. 다른 PC에서 "docs/submission/persona.md대로 시연 영상 만들어줘"라고 요청하면 됩니다.

시연 영상은 숏폼(홍보용 세로 영상)과 다릅니다. 심사자가 **이 앱이 무엇이고(서비스 개요), 어떤 기능이 어디에 있고(기능 안내), 실제로 어떻게 쓰는지(사용 시나리오)** 를 순서대로 이해하도록 만듭니다. 시연 페르소나는 기획서(`02-app-introduction.md`) 4장의 **40대 아빠 A씨** 하나이며, 앱에 넣는 지난 기록·앱의 시연 코스·영상 장면이 모두 A씨의 일주일입니다(실제 사람의 기록이 아닌 시연용 가상 기록).

| 항목 | 내용 |
|---|---|
| 길이 | 약 2분 30초 |
| 형식 | 1920×1080, 30 fps, MP4 (가로) |
| 화면 | Pleos Connect 에뮬레이터 v2.1에서 앱을 실제로 돌려 녹화한 화면만 (앱 영역 1705×1210을 잘라 씀). 지어낸 화면·숫자 없음 |
| 소리 | 앱의 실제 음성 안내(키즈모드) + 배경음악. 음량 -16~-18 LUFS |
| 구성 | ① 서비스 개요 → ② 기능 안내(메뉴별) → ③ A씨의 일주일(사용 시나리오) → 엔딩 |
| 만드는 곳 | `tools/demo/burung-demo/` (녹화 `record.py` → 클립 `prepare_clips.py` → 편집 `build.py`, HyperFrames) |

## 1. 앱 서비스 개요 (영상 ①에 쓰는 내용)

**한 줄 소개:** 「부릉탐험대」는 주행이 기록이 되고, 기록이 탐험이 되는 Pleos Connect 차량 앱입니다. 시동을 걸면 앱을 열지 않아도 달린 길이 나만의 탐험 지도에 쌓입니다.

**핵심 가치 3가지 (기획서 3장 '차량 내 새로운 사용자 경험')**

1. **운전이 나만의 탐험 지도가 됩니다.** 출퇴근도, 주말 나들이도 지도와 지역 도감에 쌓여 내가 넓혀 온 세계를 한눈에 봅니다.
2. **새로운 지역으로의 주행을 경험합니다.** 내 기록을 바탕으로 아직 안 가 본 동네·이번 주 탐험을 제안하고, 목적지가 있으면 조금만 돌아가는 길을 알려 줍니다. 제안은 현대차 내비 안내로 바로 이어집니다.
3. **함께 탄 가족도 탐험대원이 됩니다.** 함께 달린 날은 '오늘은 함께 탐험했어요!'로 남고, 키즈모드는 아이 눈높이의 말투로 안내합니다.

**화면 구성:** 왼쪽 레일의 메뉴 4개 — **지도**(주행·시연 주행), **도감**(지역별 개척 현황), **내 탐험**(칭호·스탬프·주간 추천), **설정**. 주행 중(D단)에는 지도와 짧은 정보만 보이고 조작은 P단에서만 됩니다.

**차량 특화(Pleos SDK)**: 시동 연동(부팅 시 기록 서비스 자동 시작), FusedLocation 위치, Vehicle 기어·도어·좌석·주행 가능 거리, NaviHelper 집·회사·즐겨찾기·목적지·경로 요청·경유지 추가, TextToSpeech 온디바이스 음성. 각 장면 옆에 "사용 데이터"로 작게 표시합니다.

## 2. 기능 안내 (메뉴별, 영상 ②에 쓰는 내용)

화면의 글자는 앱에 보이는 그대로 적었습니다(2026-11-02 앱 기준).

### 앱 구동

- 시동(차량 부팅)이 걸리면 기록 서비스가 자동으로 시작됩니다. 앱 화면을 열지 않아도 기록됩니다.
- 앱을 열면 로딩 화면("시동을 걸면 시작되는 나만의 탐험 지도")에서 행정구역과 탐험 기록을 불러온 뒤 지도로 들어갑니다.
- 처음 쓰는 날에는 내비에 저장된 '집'(베이스캠프) 주변만 밝고 나머지는 어둡게 덮여 있으며, Lv.1에서 시작합니다.

### 지도

| 화면 요소 | 하는 일 |
|---|---|
| 왼쪽 위 레벨 게이지 | Lv, 지금 있는 시·군·구 / 동, 다음 레벨까지 % |
| 최근 주행 | 이번 주 요약(주행 횟수·거리·새 동), 날짜별 주행("집 → 유치원"처럼 내비 즐겨찾기 이름). 한 건을 누르면 걸린 시간·새 길 비율·탐험 면적·받은 스탬프와 경로 다시 보기, **이 주행 삭제** |
| 안 가본 동네 가보기 (아래 카드) | 정차 중에 가까운 안 가 본 동네를 추천. **내비 안내**(현대차 내비로 경로 요청) · 지도에서 보기 · 다른 곳 · 오늘 안 보기 |
| 탐험 우회 경로 제안 (아래 카드) | 내비에 목적지가 있으면 출발 전 "1분 더 쓰면 안 가 본 동네를 지나요" → **경유지 추가**(내비 경로에 경유지). 주행 가능 거리로 무리한 제안은 거름 |
| 오른쪽 아래 | 확대·축소, 내 위치 |
| 주행 모드 (D단) | 지나간 길만 밝게 열리고 노란 개척로로 남음. 위쪽에 Lv·이번 주행 탐험 면적·새 동 수·지금 동, 오른쪽에 회전 안내·제한속도. 처음 들어선 동네는 음성 안내 |
| 도착 (P단 + 문 열림) | 하차 지점에 깃발, **주행 결과 카드**: '오늘은 함께 탐험했어요!'(동승자가 있을 때) · 레벨 업 · 이번 주행 요약(면적·거리·새 길 %) · 처음 가 본 동네 · 새 칭호 · 새 스탬프 · 닫기 |

### 시연 주행 (시연 모드)

에뮬레이터는 실제로 달릴 수 없어서, 실제 도로 코스를 자동으로 달리는 시연 모드가 있습니다. 위치·기어·도어·좌석 신호를 실제 차량 데이터와 같은 경로로 넣으므로 기록·스탬프·칭호가 실제와 똑같이 쌓입니다.

1. **지도** 화면 오른쪽 위 **시연 주행**을 누릅니다.
2. **시연 코스**를 눌러 코스를 고릅니다(코스마다 거리·예상 시간·동승자·제한속도 표시).
3. **속도**의 −/+ 로 차량 속도를 정합니다(20–200 km/h, 주행 중에도 바로 바뀜. 시연 시간은 실제보다 10배 빠르게 흐름).
4. 필요하면 **같은 길로 돌아오기**(도착해 하차한 뒤 출발지까지 왕복)를 켭니다.
5. **시연 시작** → 출발 전 우회 제안 → 주행 → 도착(P단 + 문 열림) → 결과 카드 순서로 진행되고, 끝나면 '시연 주행 완료'가 보입니다.
6. **시연 중지**를 누르면 언제든 멈추고 실제 위치로 돌아갑니다. 끝난 뒤에는 **다시 달리기**도 됩니다.

같은 설정이 **설정 › 시연 모드**에도 있습니다. 코스는 A씨의 일주일 순서입니다: 평일 등원길(집 → 유치원) · 평일 출근길(유치원 → 회사) · 등원 없는 날 출근길 · 토요일 가족 나들이 8곳(올림픽공원, 남한산성, 에버랜드, 수원 화성, 스타필드, 화담숲, 두물머리, 물의정원)·가족 장보기 · 인천 송도 · 강원도 가족 여행(강릉, 분기 1회).

### 도감 (지역 도감)

- 위쪽 칩으로 **전국, 서울, 경기, 인천, 부산 …** 행정구역을 넘기며(밀어서 넘기기) 지역별 주행 데이터를 한눈에 봅니다. 칩의 숫자는 가 본 시·군·구 수 / 전체(예: 서울 3/25).
- **전국**: 대한민국 지도에 가 본 시·도를 색칠, 시·도 · 시·군·구 · 읍·면·동 개척 수(예: 2/16 · 8/230 · 73/3,559). 울릉도·독도는 경북 앞바다 상자에, 제주는 조금 위로 당겨 한 화면에 그림.
- **시·도(서울·경기 등)**: 그 지역 지도에 가 본 시·군·구를 색칠하고 개척률이 높은 순으로 목록.
- **최근 개척**: 가장 최근에 처음 가 본 동네와 날짜.
- **다음 탐험 후보**: 아직 안 가 본 가까운 지역(예: "인천 · 집에서 42km · 아직 안 가 봤어요") → **지도에서**.
- 시·도 목록을 누르면 그 지역으로 넘어갑니다. 경계는 행정구역 데이터(admdongkor, CC BY 4.0)를 앱에 넣어 오프라인으로 계산합니다.

### 내 탐험

- **대표 칭호와 탐험대 이름**(예: 도현 탐험대). 칭호가 없으면 '아직 칭호가 없어요'. 오른쪽에 **다음 칭호**와 남은 조건(예: "회사 주행 1회만 더!").
- **이번 주 탐험 추천**: 이번 주에 받을 만한 스탬프 3개와 진행도(월요일마다 초기화). 장소가 필요한 추천은 바로 지도·내비로 연결(예: "인천광역시 · 42 km").
- **칭호 5종**: 우리 동네 탐험가(꾸준함 스탬프 모두) · 주말 원정대(함께·여행 스탬프 모두) · 프로 출근러(평일 회사 주행 20회) · 섬 탐험가(섬 지역 가 보기) · 서울 마스터(서울 25개 구 모두). 받는 조건과 진행도가 보이고, 받은 칭호를 눌러 대표 칭호로 고릅니다.
- **스탬프 11종**: 꾸준함(첫 시동·탐험 주간·4주 연속 탐험·1,000 km 탐험), 넓힘(읍·면·동 10곳·새 도시 첫발·시·도 3곳 탐험·읍·면·동 100곳), 함께·여행(주말 드라이브·함께 탐험·멀리 떠난 날). 받은 것은 '받았어요', 못 받은 것은 진행도.

## 3. A씨

**40대 초반 아이 아빠 A씨** · 위례 거주, 양재 출근, 유치원생 아이 한 명. 탐험대 이름은 아이 이름을 딴 '도현 탐험대'.

| 구분 | 생활 | 부릉탐험대 |
|---|---|---|
| 평일 | 아침에 아이를 유치원에 내려 주고 출근, 저녁에 퇴근 | 키즈모드로 등원, 유치원 하차 깃발, 출근 20번째에 「프로 출근러」 |
| 주말 | 토요일마다 가족(아내·아이)과 가까운 곳으로 나들이 | 도감·추천으로 안 가 본 곳 고르기, 키즈모드 음성, '함께 탐험' |
| 분기 1회 | 강원도 1박 2일 가족 여행 | '멀리 떠난 날'로 「주말 원정대」, 강원이 도감에 색칠됨 |
| 바람 | 아이와 함께하는 차 안 시간과 가족 나들이를 기록으로 남기고 싶음 | 탐험대 이름으로 쌓이는 가족 기록 |

장소 (모두 실제 장소, 경로는 OSRM 실제 도로):

| 장소 | 위치 | 내비 즐겨찾기 |
|---|---|---|
| 집 (베이스캠프) | 송파꿈에그린 위례24단지, 서울 송파구 위례광장로 121 (1,810세대, 위례에서 가장 큰 단지) | 집 |

## 4. 지난 기록 (시연일 직전 19일 근무 · 약 4주)

| 구분 | 내용 | 거리 |
|---|---|---|
| 평일 등원 | 08:05 집 → 유치원 (아이 뒷좌석) | 2.5 km |
| 평일 출근 | 08:25 유치원 → 회사 | 13.6 km |
| 평일 퇴근 | 18:35 회사 → 집 | 12.2 km |
| 토요일 | 가족 나들이 왕복 (아내 앞좌석·아이 뒷좌석) | 편도 8–31 km |

## 7. 만드는 법 (다른 PC)

### 준비 (한 번)

1. 테스트 환경: `docs/SETUP.md` (`tools/setup/setup.sh all`, Windows `setup.ps1 all`) → `doctor`로 확인. 영상 도구: `setup.sh video`(ffmpeg, Node 22, HyperFrames 0.8.196 + 스킬) 후 Claude Code 다시 열기.
2. 앱 빌드·설치: `./gradlew :app:assembleDebug` → `adb install -r app/build/outputs/apk/debug/app-debug.apk`
3. 내비 즐겨찾기(에뮬레이터 내비 화면): 집 = 위례24단지아파트, 회사 = 현대자동차 본사, 장소 = 유치원(거여2동 근처)·스타필드 하남.

### 시연 기록 넣기 (찍는 날마다, 평일에)

```bash
python3 tools/demo/persona/make_persona_backup.py  # 오늘 직전 19일 근무 기록 → tools/demo/out/persona-backup.json
python3 tools/demo/prepare_demo.py --serial emulator-5554   # 앱 초기화 → 기록 불러오기 → 집에 주차
```

- 앱 설정에서 탐험대 이름을 '도현 탐험대'로, 키즈모드는 끈 채로 둡니다(5번 장면에서 켬).
- 시계는 실제 시간 그대로 찍습니다(토요일 장면도 결과 카드는 같음). Pleos 내비는 시계가 실제 시간과 다르게 새로 켜지면 "서비스 연결 중"에서 멈춥니다.
- 시연일이 주말이면 `--today`에 다음 평일을 줍니다. `--commutes 20` 이상이면 「프로 출근러」를 이미 받은 상태가 됩니다.
- 장소나 코스를 바꿀 때만: `fetch_routes.py`(실제 도로 경로, 이름을 주면 그 경로만) → `gen_courses.py`(앱 시연 코스) → 앱 다시 빌드.

### 녹화 → 편집 → 렌더링

```bash
python3 tools/demo/burung-demo/record.py part1     # 2–9: 앱 구동·지도·시연 모드 사용법·키즈모드·등원·출근
python3 tools/demo/burung-demo/record.py part2     # 10–20: 기록·도감·내 탐험·추천 경로·토요일·강원 여행·설정
# 녹화본: tools/demo/out/raw-burung/<장면>.webm (2560×1440, 30 fps, 앱 소리 포함)

cd tools/demo/burung-demo
# prepare_clips.py의 CLIPS에 장면별 (녹화본, [(시작 s, 끝 s, 배속)])을 적음 → 앱 영역만 잘라 assets/clips/*.mp4 + *.wav
python3 prepare_clips.py
# build.py의 SCENES(장면 제목·설명·사용 데이터·음성 자막·카메라)를 6장 표대로 고침
python3 build.py
npx hyperframes@0.8.196 check
npx hyperframes@0.8.196 snapshot --at 2,15,30,50,70,90,110,130,145   # 프레임을 직접 보고 확인
npx hyperframes@0.8.196 render --quality delivery --video-frame-format png -o renders/burung-demo.mp4
ffmpeg -af ebur128=peak=true …                    # -16~-18 LUFS, 피크 -1 dBFS 아래인지 측정 (들어 보지 않았다면 그렇다고 적음)
```

- 녹화 장면 길이·탭 시각은 찍어 본 뒤 화면을 보고 `record.py`에서 맞춥니다. 각 장면은 앞 장면이 남긴 상태에서 이어집니다.
- 같은 곳에 몇 분 안에 다시 도착하면 하차로 치지 않아 주행이 끝나지 않습니다. 장면을 다시 찍을 때는 앱을 재시작하고 지난 시도를 최근 주행에서 지우거나, 기록을 다시 넣고(prepare_demo) 처음부터 찍습니다.
- 13번 '내비 안내'는 내비가 떠 있어야 합니다(`record.py`가 먼저 띄움). 우회 경유지('경유지 추가')는 실제 내비 경로에 들어가지만 시연 주행은 정해진 코스를 달립니다.
- 소재: 글꼴·배경음악·아이콘은 Release `burung-media-v1`의 `burung-demo-assets.zip`, v1 녹화본은 `burung-demo-raw-v1`. 새로 찍은 녹화본도 Release에 올립니다(`.gitignore`로 저장소에는 넣지 않음).
