# 시연 영상 시나리오: 40대 아빠 A씨의 일주일

부릉탐험대의 서비스 시연 영상(심사용, 약 1분 30초)을 찍기 위한 시나리오와 시연 데이터입니다. 기획서(`02-app-introduction.md`) **4. 주요 사용 시나리오**의 A씨 이야기를 따라가면서, 심사자가 "어떤 앱이고, 무슨 기능이 있고, 어떻게 쓰는지"를 순서대로 볼 수 있게 기능을 배치했습니다.

- 화면: Pleos Connect 에뮬레이터 v2.1에서 앱을 실제로 돌려 녹화(앱 영역만, 앱 음성 포함). 지어낸 화면은 없습니다.
- 기록: A씨의 지난 4주 기록은 시연용 가상 데이터입니다(아래 3장). 영상 끝에 "시연용 예시 데이터"라고 표시합니다.
- 영상 제작: `tools/demo/burung-demo/` (HyperFrames), 녹화본은 GitHub Release `burung-demo-raw-v1`

## 1. 페르소나

**40대 초반 아이 아빠 A씨** · 위례 거주, 양재 출근, 유치원생 아이(탐험대 이름 '도현 탐험대')

| 구분 | 생활 | 앱에서 보이는 것 |
|---|---|---|
| 평일 | 아침에 아이를 유치원에 내려 주고 출근 | 등원길 하차 깃발, '함께 탐험', 출근 20번째에 「프로 출근러」 |
| 주말 | 토요일마다 가족과 가까운 공원 나들이 | 도감·추천으로 안 가 본 곳 고르기, 키즈모드 음성, '주말 드라이브' |
| 분기 1회 | 강원도 1박 2일 가족 여행 | 다음 목표: '멀리 떠난 날' → 「주말 원정대」 (영상 끝 예고) |
| 바람 | 아이와 함께하는 차 안 시간과 가족 나들이를 기록으로 남기고 싶음 | 탐험대 이름으로 쌓이는 가족 기록 |

내비(현대차 내비)에 저장해 두는 장소: 앱은 Pleos NaviHelper `getBookmarkInfo`로 읽어서 베이스캠프·주행 이름·출근 판정에 씁니다.

| 내비 즐겨찾기 | 장소 | 앱에서 |
|---|---|---|
| 집 | 위례24단지아파트 (서울 송파구 위례광장로 121) | 베이스캠프, "집 → …" |
| 회사 | 현대자동차 본사 (서울 서초구 헌릉로 12) | 「프로 출근러」 출근 판정 |
| 장소 | 유치원 (송파구 거여2동, 시연 코스 도착점) | "집 → 유치원" |

찍을 때 지킬 것:

- 주행 중에는 앱 조작 화면을 보여 주지 않습니다(실제 앱도 주행 중에는 지도만 보임). 조작은 모두 P단에서.
- 빨리 감은 구간(4·7·13)은 소리를 빼고, 음성이 나오는 순간(5·6·8·13·14)만 1배속으로 앱 소리를 살립니다. 음성 자막을 화면에 같이 띄웁니다.
- 각 장면 옆에 "사용 데이터"(Pleos SDK)를 작게 붙여, 차량 앱이어야 하는 이유가 보이게 합니다.

## 3. 시연 데이터 (지난 4주 기록)

A씨는 앱을 설치하고 4주 동안 **평일 등원·출근만** 했다고 가정합니다. 그래서 주말 나들이·함께 탐험이 영상에서 처음 열리고, 시연 당일 출근이 20번째가 되어 「프로 출근러」를 받습니다.

| 항목 | 값 |
|---|---|
| 기간 | 시연일(월) 직전 4주의 평일 (개천절 대체공휴일·한글날 제외), 출근 19일 |
| 주행 | 38건(출근 19 + 퇴근 19), 462 km, 하차 19곳 |
| 레벨 | Lv.9 |
| 도감 | 시·도 2곳(서울·경기), 시·군·구 4곳, 읍·면·동 7곳 |
| 스탬프 | 4/11 (첫 시동, 새 도시 첫발, 탐험 주간, 4주 연속 탐험) |
| 칭호 | 아직 없음, 「프로 출근러」 19/20 |

기준 자료: 자동차 1대당 하루 평균 주행거리 38.7 km(2024, 한국교통안전공단), 수도권 평균 통근 거리 20.4 km(통계청·SKT, 2023). 경로는 OSRM 실제 도로입니다.

시연 코스(앱의 '시연 주행'): `등원길: 집 → 유치원`(2.5 km, 뒷좌석 아이), `출근길: 유치원 → 회사`(13.6 km), `토요일 올림픽공원 나들이`(8.0 km, 앞·뒤 동승), `강릉 경포대 여행 (분기 1회)`(203 km, 예고·추가 촬영용).

영상에서 열리는 것 (2026-11-02 에뮬레이터에서 확인):

| 주행 | 결과 카드 |
|---|---|
| 집 → 유치원 | 오늘은 함께 탐험했어요!, 처음 가 본 동네 1곳(거여2동), 새 스탬프 '함께 탐험' |
| 유치원 → 회사 | 처음 가 본 동네 11곳, **새 칭호 「프로 출근러」**, 새 스탬프 '읍·면·동 10곳' |
| 집 → 올림픽공원 (토) | 처음 가 본 동네 9곳, 새 스탬프 **'주말 드라이브'** |

## 4. 기획서 시나리오와 맞추기

기획서 4장 표의 이름 중 앱에 없는 것이 있어, 영상은 앱의 실제 이름을 씁니다. 기획서 표도 아래처럼 바꾸면 영상과 같아집니다.

| 기획서 | 앱(영상) |
|---|---|
| 회사 도착: '함께 탐험' 스탬프, 등원 마스터 칭호 | 유치원 도착: '함께 탐험' 스탬프 / 회사 도착: 「프로 출근러」 칭호 (평일 회사 20번째) |
| 공원 도착: '주말 탐험가' 스탬프, '프로 모험가' 스탬프 | 공원 도착: '주말 드라이브' 스탬프 (+ 처음 가 본 동네) |
| 평일 왕복 20 km | 시연 코스 기준 집 → 유치원 → 회사 16 km, 퇴근 12 km |

## 5. 준비와 촬영

```bash
python3 tools/demo/persona/fetch_routes.py kinder kinder-hq olympic   # 장소를 바꿀 때만: 실제 도로 경로 → routes.json
python3 tools/demo/persona/gen_courses.py                             # 앱의 시연 코스(DemoCourses.kt)
python3 tools/demo/persona/make_persona_backup.py --today 2026-11-02 --weeks 6 --commute-only --commutes 19
python3 tools/demo/prepare_demo.py --serial emulator-5554             # 앱 초기화 → 기록 불러오기
```

- 내비 즐겨찾기에 집·회사(필수)와 유치원(장소)을 등록해 둡니다. SDK에는 즐겨찾기를 쓰는 API가 없어 내비 화면에서 한 번 등록합니다.
- 탐험대 이름 '도현 탐험대'(설정), 키즈모드는 끈 채로 시작해 3번 장면에서 켭니다.
- **시계:** 평일 장면은 월요일 아침, 토요일 장면은 토요일로 바꿔 찍습니다(설정 › 날짜 및 시간, 자동 시간 끔). Pleos 내비는 시계가 실제 시간과 다른 상태로 새로 켜지면 "서비스 연결 중"에서 멈추므로, **실제 시간으로 내비를 먼저 띄운 뒤** 시계를 바꿉니다. 토요일은 실제 날짜보다 앞선(미래) 날을 피합니다.
- **12번 추천 경로:** '경유지 추가'는 실제 내비 경로에 경유지를 넣지만, 시연 주행은 정해진 코스를 달립니다. 화면을 맞추려면 우회 경유지를 지나는 올림픽공원 코스를 따로 만들어 둡니다(경유지 좌표를 fetch_routes.py의 LEGS에 추가).
- 한 장면을 다시 찍을 때 같은 곳에 몇 분 안에 다시 도착하면 하차로 치지 않아 주행이 끝나지 않습니다. 다시 찍기 전에 앱을 재시작하고, 지난 시도는 최근 주행에서 지웁니다.
- 찍은 뒤에는 `make_persona_backup.py`(기본 4주) → `prepare_demo.py`로 평소 시연 기록으로 되돌리고, 자동 시간을 다시 켭니다.
