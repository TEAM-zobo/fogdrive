# 숏폼 (선택)

접수양식 02-8에 링크를 적는 세로 영상입니다. 본상 가산점은 없고, 별도 특별상(50만 원)이 있습니다.

- 파일: `tools/demo/shortform/renders/fogdrive-shortform.mp4` (1080×1920, 30fps, 47초, git 제외). 만드는 방법은 [docs/VIDEO.md](../VIDEO.md#5-숏폼)
- 가이드: 길이 30초–1분, 세로 9:16(1080×1920), Instagram 릴스 또는 YouTube Shorts에 게시. 필수 해시태그 `#HMG차량용앱개발공모전`을 포함해 **해시태그 총 2~3개**를 본문·설명란에 달아야 정상 참여로 인정(제안: `#PleosAppMarket` `#HMG앱공모전`). 근거: [숏폼 챌린지](https://appdevchallenge.auto-hmg.io/guide/shortform), [FAQ](https://appdevchallenge.auto-hmg.io/faq)
- 게시 채널과 세부 조건: 공모전 「숏폼 챌린지」 안내를 따릅니다(게시 전 다시 확인)
- 계정: 실명·개인 계정이 드러나지 않게 팀 zobo 계정으로 올립니다
- 소재: 홍보 영상과 같은 실제 에뮬레이터 녹화본을 세로로 다시 짠 것. 누적 기록은 시연용 예시(마지막 화면에 표시)

## 장면 (47초)

글자와 앱 화면의 핵심은 모두 화면 위 168–1330 px 안에 둡니다(그 아래는 플랫폼의 설명·버튼이 덮음). 첫 프레임에 질문이 이미 떠 있어서 썸네일이 됩니다.

| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 0–4초 | 온통 안개 속에서 차 주변만 걷힘 | 우리 동네, 얼마나 가 봤을까? |
| 4–9초 | 달리는 길을 따라 안개가 걷힘 | 시동만 걸면, 달린 길의 안개가 걷혀요 |
| 9–15초 | 앱 음성 안내(실제 소리) | 처음 가 본 동네는, 차가 먼저 알려 줘요 |
| 15–19초 | 스탬프 알림(바람길 개척)으로 당겨 보기 | 창문을 연 순간까지, 스탬프로 남아요 |
| 19–24초 | 이번 주행 요약 카드 | 도착하면, 오늘의 여정이 한 장에 |
| 24–28초 | 파랑 화면 가득 0 → 4.07 km² | 첫 드라이브가 밝힌 세상 · 처음 가 본 동네 44곳 |
| 28–34초 | 자주 다닌 길 색(6단계 범례) | 자주 다닌 길은, 색이 깊어져요 |
| 34–42초 | 기록 → 도감 → 스탬프 → 내 안개지도 카드(2초씩 휙) | 매주 쌓이는 나의 기록 / 동네마다 채우는 도감 / 29가지 드라이브 스탬프 / 나만의 지도를 공유해요 |
| 42–47초 | 아이콘·안개지도, 해시태그, 출처 | 달린 만큼, 세상이 밝아집니다 · #HMG차량용앱개발공모전 |

소리: 배경음악 "Fretless"(Kevin MacLeod, CC BY 4.0), 음성 장면에서만 낮춤. 장면 전환·숫자·로고에 효과음(Pixabay, 표기 불필요).
