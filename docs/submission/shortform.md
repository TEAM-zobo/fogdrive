# 숏폼 (선택)

접수양식 02-8에 링크를 적는 세로 영상입니다. 본상 가산점은 없고, 별도 특별상(50만 원)이 있습니다. 시간이 남을 때만 만듭니다.

- 길이: 30초–1분, 세로(9:16, 1080×1920)
- 필수 해시태그: `#HMG차량용앱개발공모전`
- 게시 채널과 세부 조건: 공모전 「숏폼 챌린지」 안내를 따릅니다(게시 전 다시 확인)
- 계정: 실명·개인 계정이 드러나지 않게 팀 zobo 계정으로 올립니다

## 콘티 (45초)

| 시간 | 화면 | 자막 |
| --- | --- | --- |
| 0–3초 | 짙은 안개로 덮인 지도 클로즈업 | 우리 동네, 얼마나 가 봤을까? |
| 3–12초 | 시연 주행: 차가 달리며 도로를 따라 안개가 걷힘(배속) | 시동만 걸면 달린 길의 안개가 걷혀요 |
| 12–20초 | 새 동네 진입 음성 + 스탬프 알림 | 처음 가 본 동네는 차가 말로 알려 줘요 |
| 20–28초 | 이번 주행 요약 카드 | 오늘 밝힌 면적, 처음 가 본 동네 44곳 |
| 28–36초 | 지도 축소 → 2단계 안개, 지역 도감 | 안 가 본 동네는 아직 안개 속 |
| 36–42초 | 내 안개지도 카드 | 나만의 탐험 지도를 공유해요 |
| 42–45초 | 앱 이름 | 안개지도 · #HMG차량용앱개발공모전 |

## 만드는 방법

1. [`demo-video.md`](demo-video.md)의 촬영 준비대로 에뮬레이터를 띄우고 시연 모드(성수 주말 나들이, 120 km/h)를 녹화합니다.
2. 가로 녹화본에서 오른쪽 앱 화면(지도 부분)만 세로로 잘라 9:16으로 맞춥니다. 위아래 여백에 자막을 넣습니다.
3. 게시 후 링크를 `02-app-introduction.md`의 【기입 필요: 숏폼 링크】와 [`email.md`](email.md)에 넣고, `python3 tools/submission/build_form.py`로 양식을 다시 만듭니다.
