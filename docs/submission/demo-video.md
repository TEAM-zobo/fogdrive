# 시연 영상

접수양식 02-7 참고자료에 넣는 시연 영상(선택, 가산점)의 콘티와 촬영 방법입니다. 목업·프로토타입·화면 녹화 모두 인정되므로, Pleos Connect 에뮬레이터 화면을 녹화해 2–3분으로 만듭니다.

- 길이: 2분 30초 안팎(3분 넘지 않게)
- 화면: 에뮬레이터 전체(2560×1440, 왼쪽 차량 패널 포함)를 1920×1080으로 내보내기
- 소리: 앱 음성 안내 + 자막. 내레이션은 선택
- 공개: YouTube **일부 공개**(링크가 있는 사람만). 채널 이름·프로필에 실명이 보이면 안 되므로 팀명 zobo로 된 채널을 쓰거나, 링크 공유가 되는 클라우드 드라이브(소유자 이름이 보이지 않게)를 씁니다.

## 콘티

| # | 시간 | 화면 | 하는 일 | 자막 |
| --- | --- | --- | --- | --- |
| 1 | 0:00–0:10 | 앱 아이콘 → 로딩 → 지도 | 앱 실행 | 시동만 걸면 달린 길의 안개가 걷히는 차량 전용 탐험 지도, 안개지도 |
| 2 | 0:10–0:25 | 첫 실행 튜토리얼 1/5 → 지도 | 튜토리얼 넘기기 | 내비 최근 목적지·즐겨찾기 주변을 미리 밝혀, 첫날부터 빈 지도가 아니에요 |
| 3 | 0:25–0:40 | 지도 → 시연 주행 패널 → 성수 주말 나들이 | 코스 선택, 시연 시작 | 출발 전(P단): 1분 더 쓰면 안 가 본 동네를 지나는 우회 경로를 제안해요 |
| 4 | 0:40–1:20 | 주행 모드 | 속도 120 km/h, 회전 안내·제한속도·새 동 카운트가 오르는 장면, 비 시작 | 주행 중엔 지도·위치·회전 안내만. 도로와 길에서 보이는 만큼만 안개가 걷혀요 |
| 5 | 1:20–1:35 | 주행 모드 | 새 동네 진입 음성, 스탬프 토스트 | 처음 들어선 동네는 음성으로, 스탬프는 화면 알림으로 |
| 6 | 1:35–1:55 | 도착 → 이번 주행 요약 카드 | 하차 지점 기록 | P단 + 도어 열림 = 하차 지점. 이번 주행에 밝힌 면적·처음 가 본 동네·스탬프를 한눈에 |
| 7 | 1:55–2:10 | 지도 축소 → 안 가 본 동네 추천 | 2단계 안개 보여 주기 | 안 가 본 동네는 짙은 안개, 들어가 본 동네는 옅은 안개 |
| 8 | 2:10–2:25 | 도감 → 스탬프 → 기록 → 내 안개지도 카드 | 탭 이동 | 지역 도감, 상황 스탬프 29종, 공유 카드 |
| 9 | 2:25–2:35 | 설정 → 연결 상태 | SDK 연결 표시 | Pleos Vehicle · NaviHelper · FusedLocation 실제 SDK로 동작 |
| 10 | 2:35–2:40 | 로고 화면 | - | 안개지도(FogDrive) · 팀 zobo |

장면 4–6의 빗속·동승자 이벤트는 「성수 주말 나들이」 코스에 들어 있습니다(창문 열기 → 비 → 뒷좌석 동승자). 야간 장면을 원하면 「여의도 야경 드라이브」로 한 번 더 찍어 장면 4에 이어 붙입니다.

## 촬영 준비

1. 테스트 환경을 띄웁니다: macOS `tools/setup/setup.sh all`, Windows `tools\setup\setup.ps1 all` ([`../SETUP.md`](../SETUP.md)).
2. 앱을 초기화합니다: `adb shell pm clear --user current com.zobo.fogdrive` 후(AAOS에서 앱은 운전자 사용자로 실행되므로 `--user current`가 꼭 필요합니다) `tools/setup/setup.sh app` (권한 자동 허용으로 다시 설치·실행).
3. 에뮬레이터 위치가 향기5로 66(고양 향동)인지 확인합니다. 모든 시연 코스가 여기서 출발합니다.
4. 기어는 P. 에뮬레이터는 P가 아니면 앱 화면을 가립니다(시연 모드는 실제 기어를 바꾸지 않으므로 P 그대로 둡니다).
5. 소리: 에뮬레이터 오디오가 켜져 있어야 음성 안내가 녹음됩니다(`-no-audio`로 띄운 QA 에뮬레이터는 안 됨).

## 녹화 방법

| 방법 | 명령 / 위치 | 비고 |
| --- | --- | --- |
| 에뮬레이터 내장 녹화 | 에뮬레이터 옆 `…` → Record and Playback → Start recording | 소리 포함 webm. 가장 간단 |
| adb | `adb shell screenrecord --size 1920x1080 --bit-rate 12000000 /sdcard/demo.mp4` → `adb pull /sdcard/demo.mp4` | 최대 3분, 소리 없음. 장면별로 끊어 찍기 |
| macOS 화면 녹화 | ⌘⇧5 → 선택 영역 녹화(에뮬레이터 창) | 소리를 넣으려면 오디오 루프백 도구 필요 |
| Windows 화면 녹화 | Win+Alt+R(Xbox Game Bar) 또는 OBS | 에뮬레이터 창만 잡기 |

편집은 iMovie·CapCut·DaVinci Resolve 등 아무것이나 됩니다. 자막은 위 표를 그대로 씁니다.
