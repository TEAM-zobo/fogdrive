# 시연 영상

접수양식 02-7 참고자료에 넣는 시연 영상(선택, 가산점)입니다. 만드는 방법 전체(도구 설치, 녹화, 편집, 렌더링, 수정, 라이선스)는 **[docs/VIDEO.md](../VIDEO.md)** 에 있습니다. 이 문서는 제출용으로 무엇이 담겼는지와 올리기 전 확인만 다룹니다.

- 파일: `tools/demo/promo/renders/fogdrive-promo.mp4` (1920×1080, 30fps, 1분 46초, git 제외)
- 화면: 실제 Pleos Connect 에뮬레이터 v2.1.0에서 녹화한 앱 화면. 지어낸 화면이나 숫자는 없습니다(숫자는 앱 화면의 실제 값)
- 소리: 배경음악 "Fretless"(Kevin MacLeod, CC BY 4.0), 앱의 실제 음성 안내 한 문장, 전환·착지 효과음(Pixabay, 표기 불필요)
- 누적 기록 장면은 시연용 예시 기록(앱의 시연 코스를 2~52번 오간 기록)이며, 엔딩 화면 하단에 그렇게 표시합니다
- 공개: YouTube **일부 공개**(링크가 있는 사람만). 채널 이름·프로필에 실명이 보이지 않게 팀 zobo 채널을 쓰거나, 소유자 이름이 보이지 않는 클라우드 링크를 씁니다
